# ClubOps AI — Client

Frontend client for ClubOps AI built with React, Vite, and Tailwind CSS.

## Ownership
* **Primary Owner**: Member 1 (Product & Frontend)
* **Scope**: UI components, pages, layouts, routing, client-side state, API client services.

## Directory Layout
* `src/assets/`: Media and static graphics
* `src/components/`: Modular UI elements (`common`, `layout`, `ui`, `forms`, `ai`)
* `src/pages/`: Page views corresponding to core features
* `src/layouts/`: Base layouts (e.g. AppLayout, AuthLayout)
* `src/routes/`: Route definitions
* `src/services/`: HTTP API and AI client wrappers
* `src/hooks/`: Reusable custom React hooks
* `src/context/`: Global React context providers
* `src/store/`: Client state stores
* `src/utils/`: Formatting and helper utilities
* `src/constants/`: App constants, theme tokens, routes enum
* `src/types/`: Prop contracts and data shape definitions

## Development
```bash
npm install
npm run dev
```
Runs the Vite dev server on `http://localhost:5173`.
